# Security

## Reporting a vulnerability

Please don't open a public issue for security problems. Report them privately through GitHub instead:
**Security › Report a vulnerability** on this repo ([direct link](https://github.com/rmb707/Duos-Public/security/advisories/new)).

If you can't use GitHub, email [support@norfbay.com](mailto:support@norfbay.com) instead. Include what's affected, how
to reproduce it, and the Duos version and phone you used. I'll reply in the report.

## Supported versions

Duos is in development (0.x). Fixes go into the latest release only.
